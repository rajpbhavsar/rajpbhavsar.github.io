02 / Selected work
Open-source research release

Graph learning for spatial energy planning

A settlement-scale graph-based aggregation framework for Zambia that turns granular electrification outputs into connected, technology-characterised planning units and interpretable supply-curve bands.

  • 24,550 settlement-scale planning points
  • Variational graph autoencoder on a proximity graph
  • k-means and cost-bin baselines
  • Reproducibility scripts, checksums, tests and citation metadata
